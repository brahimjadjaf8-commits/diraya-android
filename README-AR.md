# مكتبة الشيخ جفجاف إبراهيم — Android

تطبيق Android أصلي يبدأ بمكتبة فارغة، ثم يسمح بإضافة الكتب من الهاتف.

## الوظائف الموجودة

- إضافة كتب PDF وTXT وHTML وEPUB وDOC وDOCX من ملفات الهاتف.
- نسخ الكتاب إلى مساحة التطبيق كي يبقى موجودًا بعد نقله أو حذف النسخة الأصلية.
- إدخال اسم الكتاب والمؤلف والقسم.
- البحث باسم الكتاب أو المؤلف أو القسم.
- قارئ داخلي لملفات TXT وHTML مع تكبير وتصغير الخط.
- فتح PDF وEPUB وWord في القارئ المناسب الموجود على الهاتف.
- تعديل بيانات الكتاب بالضغط المطول عليه.
- حذف الكتاب وملفه من داخل التطبيق.

ملف APK ينتج آليًا من صفحة Actions داخل GitHub.

تم تجهيز البناء التلقائي لملف APK عبر GitHub Actions.
